# 鑑定クエスト

不動産鑑定評価基準を学ぶ、4案件・各3問のブラウザゲームです。

## 起動

Node.js 22 で確認。初回は `npm install`、続いて `npm run dev` を実行し、http://localhost:3000 を開きます。本番用は `npm run build` の後に `npm start`。

## 遊び方

「クエストをはじめる」で4案件を順に調査します。案件カードからは1案件だけ遊べます。「地域分析」「個別分析」のカードで情報を集め、類型・最有効使用・評価方針を順番に判断。結果画面で正解・解説・音声を復習します。第1案件で2問以上正解するとSSR更地を解放し、図鑑で原文を復習できます。

正解1問につき100ポイント。知識EXPは各案件の最高成績の合計で、繰り返しによる無制限加算はありません。端末に最高成績・キャラ解放を保存し、未習得の案件を復習できます。保存できないブラウザでもその回は遊べます。旧版の学習記録は読み込み時に引き継ぎます。途中の回答状態は再読み込みでリセットします。

## 教材の扱い

出典：国土交通省「不動産鑑定評価基準」（平成26年5月1日一部改正） https://www.mlit.go.jp/common/001037632.pdf

総論第2章第2節、各論第1章第1節・第2節を参照。確認日：2026-09-23。国交省の資料一覧：https://www.mlit.go.jp/totikensangyo/totikensangyo_tk4_000024.html

案件は創作、解説は要約です。更地の定義は原文で表示・読み上げし、他案件の要点は要約と明示しています。最有効使用は用途地域だけでは確定しないため、実現可能性や代替案比較の調査結果を前提条件として提示しています。「建付地」は敷地だけ、「借地権付建物」は建物と借地権、「貸家及びその敷地」は賃貸建物とその所有地を対象とし、対象範囲を明示しています。

## 構成・拡張

- `data/cases.ts`：問題・正解・解説・資料への参照先
- `app/page.tsx`：案件選択、回答、採点、復習、音声、成績保存
- `app/globals.css`：画面と地図の装飾、スマホ対応

Next.js / TypeScript / CSS を使用。音声は端末の Web Speech API のため声質・利用可否は環境によります。音声制御は自動テストで検証、実際の音質は未評価です。更地キャラ1体と4案件すべての背景を用意し、画像はpublic/artに保存。生成プロンプトはART_DIRECTION.mdを参照。全範囲網羅・無限案件生成・デッキ編成・実務の評価額計算は未実装です。外部フォントが利用できなくても端末の日本語フォントで表示します。

## 確認

`npm run build` / `npm run typecheck`。ブラウザ検証は `npx playwright test`（起動中の開発サーバーを利用）。
